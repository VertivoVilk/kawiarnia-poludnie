# Kawiarnia Południe

Prosta, jednoplikowa strona landing page dla (fikcyjnej) kawiarni „Kawiarnia Południe". Czysty HTML i CSS, bez zewnętrznych bibliotek, w całości po polsku.

## Podgląd

Otwórz `index.html` w przeglądarce albo uruchom dowolny statyczny serwer plików w tym katalogu.

## Struktura

- `index.html` — cała strona (style, sekcje: powitanie, o nas, oferta, stopka, inline SVG)
- `CLAUDE.md` — wytyczne projektowe dla Claude Code
